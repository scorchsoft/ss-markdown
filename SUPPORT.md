# Getting help

SS Markdown is free and open source, and it is supported by its community
here on GitHub. There is no private or paid support channel.

- **Something not working?** Search the
  [issues](https://github.com/scorchsoft/ss-markdown/issues) first; if it
  isn't there, open a bug report with the app version (Settings → About),
  your phone and Android version, and the steps that cause it.
- **An idea or a question?** Open a feature request or an issue. Please
  read [`docs/product-journey.md`](docs/product-journey.md) first: the app
  stays deliberately calm, so not every feature will fit.
- **A security problem?** Never in a public issue: follow
  [SECURITY.md](SECURITY.md).

Issues are read and answered when the maintainers can, with no guaranteed
response time. Pull requests that fix a bug with a test are the fastest way
to get something changed; see [CONTRIBUTING.md](CONTRIBUTING.md).
