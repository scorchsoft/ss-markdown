# Brand

The SS Markdown logo: "SS" over "M↓" (the Markdown mark), white on red
`#AD0E0D`.

| File | What it is |
|---|---|
| `ssmd-logo.svg` | The master: red square and white glyphs, 1024 × 1024 viewBox. |
| `ssmd-glyph.svg` | The white glyphs alone on transparent, same coordinates. |
| `logo.png`, `logo-240.png` | Renders of the master (the README uses `logo-240.png`). |

The glyphs are lines and circular arcs fitted to Andrew's raster logo
(mean difference under 1% of a pixel's range; edges within about one
source pixel). The launcher icon
(`apps/android/app/src/main/res/drawable/ic_launcher_foreground.xml`) is
the same paths, scaled so the glyph block's diagonal is 64 dp on the
108 dp adaptive-icon canvas. Change the master first, then the icon.
